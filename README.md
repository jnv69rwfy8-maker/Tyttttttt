# The Logic Matrix

تطبيق ويب تفاعلي — غرفة هروب برمجية تمزج بين:

- **Terminal غامض** (قصة + تحديات + شفرات)
- **محول ملاحظات → خريطة ذهنية** في الوقت الفعلي
- **مختبر منطق بصري** (بلوكات مثل Scratch تولّد كود + مخطط انسيابي)

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو ارفعه على **GitHub Pages**:

1. ارفع الملفات على مستودع GitHub
2. من Settings → Pages → Source: اختر الفرع `main` ومجلد `/ (root)`
3. التطبيق هيشتغل على الرابط: `https://yourusername.github.io/repo-name/`

## كيف تلعب

1. ابدأ من **الكونسول** — اكتب `help` للأوامر
2. روح لـ **الخريطة الذهنية** واضغط "عينة القصة" عشان تحلل المعطيات
3. في **مختبر المنطق** ابني الفلاتر بالسحب والإفلات
4. ارجع للكونسول جرب الحلول أو كلمات المرور

### كلمات مرور سرية (Easter Eggs)
- `abogallab`
- `4-2-2-2`

## التقنيات

- HTML + CSS + Vanilla JavaScript فقط
- لا يوجد Backend
- متجاوب بالكامل (موبايل + آيباد)
- دعم RTL / الكتابة العربية
